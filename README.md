# IRONEX Garage

Premium automotive repair garage website for London, UK.

Established in 2013. Offering professional vehicle diagnostics, repairs, servicing, and premium automotive care for drivers across London.

## Local Development

```bash
python -m http.server 3200
```

Then open: [http://localhost:3200](http://localhost:3200)

## Deployment

Static site deployed via **GitHub Pages**.

- Branch: `main`
- Folder: `/ (root)`

## Tech Stack

- HTML5
- Vanilla CSS (custom design system)
- Vanilla JavaScript
- AI-generated images (no licensing restrictions)

## Forms

> **Note:** Contact and popup forms are frontend placeholders only. They are not connected to any email service or CRM. Connect to a backend (e.g., Formspree, EmailJS, or custom API) before launch.
